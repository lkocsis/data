# _github.py

This module provides functions to upload and download files to/from GitHub repositories using the GitHub API.

## Functions

- `github_up`: Uploads a local file to a specified GitHub repository, creating or updating the file as needed.
- `github_down`: Downloads a file from a specified GitHub repository to a local path.

## Usage

1. Set your GitHub token and repository information in the variables at the top of the script.
2. Use the `github_up` function to upload files and the `github_down` function to download files.
